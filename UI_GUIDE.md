# AI Changing Room - UI & Design Guide

## Design Philosophy

The application should feel premium, modern, luxurious, and easy to use.

Avoid a generic admin dashboard appearance.

Focus on smooth user experience, beautiful animations, and clean layouts.

# UI Rules

- Never clutter the interface.
- Maintain consistent spacing.
- Use 8px spacing system.
- Keep navigation simple.
- Prioritize readability.
- Ensure every page feels premium.
